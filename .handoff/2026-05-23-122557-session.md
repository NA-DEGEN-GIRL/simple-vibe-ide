## Important Decisions
- Favor responsiveness over aggressive background freshness. Defer hidden/background/prefetch/watch/cache-prune/snapshot/console-replay/terminal-write work behind UI-idle and input-pending guards where behavior remains acceptable.
- Preserve terminal, Browser, and Explorer behavior, but avoid large synchronous string concatenation, filtered arrays, repeated tab/widget/proxy/device scans, path split/filter/pop arrays, locale lowercasing in Explorer typeahead, and large one-shot `xterm.write` bursts on activation/switch/render/snapshot paths.
- Distinguish Browser user-visible immediate work from hidden/unused console/frame/proxy/device sizing work; active/open-existing Browser tab, preview-proxy, and device preset lookup should be O(1) in common cases.
- Prioritize workspace first paint/first interaction; delayed snapshot persistence is acceptable if existing save/switch flush paths remain intact.
- UI render signatures and workspace snapshots should avoid avoidable allocation in frequent save/render checks; structural changes still use full render fallback where needed.
- Actual repo state remains source of truth over old handoff snapshots.
