## Known Issues / Errors
- Error: Explorer feels very sluggish when scrolling after workspace switches or in large trees.
  - Repro: open a WSL/SSH workspace with enough files/folders, switch workspaces, then scroll Explorer up/down quickly.
  - Suspected cause before latest patch: too many row DOM nodes/listeners plus hover-triggered file/directory prefetch during scroll.
  - Current mitigation: virtual rows + delegated events + scroll-time prefetch pause. Needs real app verification.
- Error: Browser preview can differ from Chrome.
  - Repro: complex local dev apps with auth/socket/popup/devtools expectations may work in Chrome but behave differently in IDE preview.
  - Suspected cause: iframe/proxy model, browser policy headers, cookie/origin rewriting, and limited console bridge.
- Error: Edge DevTools preview path froze or failed endpoint readiness.
  - Repro: previous manual load attempts showed "Starting Edge browser..." and endpoint timeout/freeze behavior.
  - Current state: Edge CDP path disabled; iframe/proxy is active path.
- Error: cached `%TEMP%` exe can stay stale if app is running and locking the file.
  - Repro: build while old app process still runs, then cached exe cannot be overwritten.
  - Current mitigation: `run-built.*` now copies fresh repo release exe when possible; user should fully close app before rerun.
