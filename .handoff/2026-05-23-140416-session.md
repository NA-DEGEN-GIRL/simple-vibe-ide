- Favor responsiveness over aggressive background freshness. Defer hidden/background/prefetch/watch/cache-prune/snapshot/console-replay/terminal-write work behind UI-idle and input-pending guards where behavior remains acceptable.
- Preserve terminal, Browser, Explorer, Editor, Image, Notes, forwarding, profile, and workspace-tab behavior while avoiding large synchronous string concatenation, repeated scans, repeated directory-cache key construction, repeated DOM queries, Browser tab `innerHTML` parse/query cycles, one-element arrays on hidden Browser console records, hidden-console compact object key arrays, preview-proxy local-port fallback scans in common paths, intermediate arrays, spread pushes on noisy batches, temporary splice batch arrays for hidden Browser console local-port scans, synchronous all-entry Explorer directory cache prune, and large one-shot terminal writes.

- Explorer cache pruning should defer while scrolling/input is active, with bounded hard-limit pruning only if cache growth exceeds busy ceilings.
- Browser console visible state should reuse DOM where possible and keep hidden-log replay, hidden queue pruning, and hidden local-port scans deferred/batched so Browser tabs do not feel heavy when unused.
- Prioritize workspace first paint/first interaction; delayed snapshot persistence is acceptable if existing save/switch flush paths remain intact.
