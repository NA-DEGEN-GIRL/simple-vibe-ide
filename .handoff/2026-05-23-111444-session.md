## Important Decisions
- Favor responsiveness over aggressive background freshness. Defer hidden/background/prefetch/watch work behind UI-idle and input-pending guards where behavior remains acceptable.
- OSC7 terminal cwd updates remain immediate; fallback prompt-regex cwd detection is skipped for background/document-hidden panes, and background cwd snapshot saves are deferred or skipped when the pane belongs to a non-active workspace.
- Terminal fit/layout/active-state/render work should run for active visible panes and affected widgets only; inactive tabs and hidden workspace widgets should wait until activation/show where possible.
- Browser console/tab/frame/sizing work should distinguish active/visible use from hidden/unused state and avoid allocating/rendering/toggling/style-writing unless needed.
- Workspace restore should avoid redundant control/panel DOM writes while synchronizing state.
- Workspace tab activation should use targeted previous/next element updates only when the DOM cache is connected and order is stable; fall back to full render for structural changes.
- Explorer prefetch/watch should warm caches and detect changes without competing with input/scroll frames.
- Actual repo state remains source of truth over old handoff snapshots.
